# Gate13R-AX2 四算法公平性契约 v1

协议 ID：`gate13r-ax2-four-algorithm-fairness-v1`

## 共同工作负载

四种算法接收相同的 canonical scenario、固定 agent 起点、单一共享目标、连通性、切角策略、地形入格成本、动态变更序列和逐操作预算。场景在一个完整 block 内不得因算法而变化。

## 状态模型

- `BiA*-R`：单 planner 实例；每次规划请求完整重建双向搜索状态；`ApplyChanges` 仅确认新 grid version；
- `LPA*`：单 planner 实例；每个 agent 保留独立的固定起点 goal-rooted `g/rhs/queue` 状态；动态变更后修复所有已实例化 agent 状态；
- `C-FF`：沿用冻结实现，单一共享多源场，动态事件后完整重算；
- `IDFF`：沿用冻结实现，单一共享增量多源场，动态事件后局部修复。

不同算法保留其原生状态模型；不得人为强制相同内部数据结构。公平性来自相同外部任务、相同计时边界、相同正确性约束和同期配对，而非内部工作量同构。

## 图与成本语义

- 节点为可通行网格 cell；
- 正向边 `u→v` 的代价为 `traversalCost(v) × distance(u,v)`；
- 四向距离为 1；对角距离为 `sqrt(2)`；
- 禁止切角时，对角移动的两个正交侧邻均须可通行；
- 所有成功路径必须与上述有向入格成本语义下的最短路径一致。

`BiA*-R` 的反向前沿遍历正向边的逆边时，必须使用原正向边 `c(u,v)`，即按被反向前沿当前节点 `v` 的入格成本计费。`LPA*` 在 Gate 13R 固定起点协议中不得执行 D* Lite 式的起点迁移。

## 计时和输出

P1 使用现有 Gate 13R 工作负载记录的动态处理计时边界。不得为任何算法增加或删除事件、规划调用或结果验证。原生 `processed/expanded/relaxed/repaired` 仅用于实现审计，不作为跨算法等价工作量。

## 隔离

Gate13R-AX2 使用独立输出 root。旧 Gate 13R raw、分析文件和只读属性均不得修改。旧 C-FF/IDFF 数值不得替代新同期测量。
