# Credentials are intentionally not included

This migration package contains no Unity account file, license activation file,
password, token, private key, `.env` file, or other credential material.

The bundled Unity installer is an installer only. The target machine must use
its own legitimately activated Unity license. `START-HERE.cmd` and the
readiness script never copy credentials and never place credentials into the
package archive.

Software license notices such as `LICENSE.txt`, `NOTICE`, or `COPYING` are
legal notices, not activation credentials, and may be present with the bundled
portable runtimes.
