# Verification Artifacts

This directory stores reproducible Gate logs generated by local validation commands. Logs are evidence, not source inputs.

## Gate 1

Close the Unity Editor, then run the following command from a normal PowerShell session:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "H:\DDM_Final_Project\Research\Verification\Run-Gate1UnityVerification.ps1"
```

The script runs Unity in batch mode and writes:

- `Gate1_Unity.log`: the complete Unity Editor log.
- `Gate1_Unity.summary.json`: exit code, compiler-error scan, assembly freshness, and the final pass/fail result.

The gate passes only when Unity exits with code `0`, the log contains none of the configured compiler-error signatures, and `Assembly-CSharp.dll` is not older than the newest research source.

The same verifier can preserve separate artifacts for later gates by passing a safe artifact name, for example:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "H:\DDM_Final_Project\Research\Verification\Run-Gate1UnityVerification.ps1" -ArtifactName Gate2_Unity
```

Gate 2 also has an Editor-only behavioral smoke check:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "H:\DDM_Final_Project\Research\Verification\Run-Gate2SmokeVerification.ps1"
```

It validates deterministic normalization and fingerprinting, grid atomicity/versioning, coordinate conversion, scheduled tick ordering, and the experiment-runner lifecycle with a non-algorithmic planner test double.
