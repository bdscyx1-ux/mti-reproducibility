| Check | Finding and boundary |
|---|---|
| Simpson's paradox | All 36 cell ratios retained; average effects do not imply a common effect in every cell. |
| Ecological fallacy | The paired unit is the superblock; six lanes and repeated event groups are not independent replicates. |
| Selection bias / Berkson's | Historical acceptance and the selected workload matrix limit inference; no new independent maps were added. |
| Collider bias | No filtering/adjustment by measured advantage or successful latency; all 7,776 lanes retained. |
| Base-rate neglect | No prevalence or diagnostic predictive-value inference; weight-grid leader counts are not probabilities. |
| Regression to the mean | Inputs are the entire frozen accepted dataset, not selected extreme speedups. |
| Survivorship bias | Completeness requires 1,296 six-lane blocks; no slow rows or unfavorable conditions removed. Historical exclusions remain part of the original acquisition record. |
| Look-elsewhere effect | All five prespecified endpoint diagnostics shown; pointwise intervals distinguished from Bonferroni intervals over only these five. No new domain-winner significance search. |
| Forking paths | Supplementary protocol fixed before new diagnostics; four weight choices and full 0.1 simplex retained, including unfavorable leaders. Existing archived sensitivities identified as earlier analyses. |
| Correlation / causation | Source-conditional sensitivity supports reporting about these implementations/workloads, not a causal universal architecture ranking or independent preference distribution. |
| Reverse causality | Data and frozen fit precede new diagnostics; no causal claim that a post hoc score generated performance. |

Residual spreads are diagnostic evidence, not a homoscedasticity certificate. The GLS sandwich uses plugged-in frozen variance parameters, assumes independent superblocks and does not repair a misspecified conditional mean. The paired bootstrap estimates a separate workload-average transformed difference. A resource-shifted ratio must not be renamed an unshifted byte ratio. Original rank uncertainty is not recalibrated by this supplement. D*L/LPA* relatedness and changing weight leaders limit architectural claims. No p-values or power statements are invented.
